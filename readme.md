# Photography Portfolio Website

A custom-built photography portfolio website created from scratch using HTML, CSS, JavaScript, and JSON.

This project was developed as a flexible alternative to traditional website builders, allowing complete control over design, features, performance, and future improvements.

The website is hosted using GitHub Pages and is designed to be lightweight, fast, and easily maintainable.

---

## Overview

This website is a dynamic photography gallery system that generates albums, galleries, searches, and features from structured data.

Instead of manually creating individual pages for every gallery, images and albums are managed through JavaScript data objects, making it easier to expand and maintain as the collection grows.

# Hosting & Image Storage

The website is hosted using GitHub Pages.

Images are primarily served from GitHub because it provides reliable direct web access for website content.

OneDrive is used as a secondary fallback/storage option where required.

This approach allows the website to remain independent while keeping full control over the content and structure.

## Translation & Community Contributions

The website supports multiple languages through external JSON translation files.

The translation system is designed to be open and community-friendly. Anyone who would like to help improve accessibility for more users can contribute translations or corrections for existing languages.

If you would like to contribute:

1. Choose an existing language file from the `/lang` folder.
2. Copy the structure of the existing English translation file.
3. Translate the text values while keeping the translation keys unchanged.
4. Submit the updated language file as a contribution.

### Translation Guidelines

- Keep the original JSON structure unchanged.
- Only translate the text values.
- Keep technical terms consistent where possible.
- Consider natural wording for native speakers rather than direct word-for-word translation.
- Report incorrect translations or missing phrases through GitHub issues.

The goal is to make the website accessible to more people around the world through community collaboration.
